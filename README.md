# ZWPipe

ZWCAD 2026용 배관 설계 도구의 배포 저장소입니다.

설치 EXE와 PDF 사용 설명서는 [Releases](https://github.com/onple/zwpipe/releases)에서 제공합니다. 이 저장소에는 프로그램 소스나 운영용 개인키를 보관하지 않습니다.

## 사용 환경

- 한국어 Windows 11 64비트, 시스템 코드 페이지 949
- ZWCAD 2026
- HTTPS 인터넷 연결

## 설치와 업데이트

설치 EXE를 실행하면 현재 사용자 계정에 프로그램과 ZWCAD 메뉴를 등록합니다. 설치 후 새 도면을 열고 `ZWPIPE` 명령을 입력하세요. 한국어·영어 화면은 설정에서 선택합니다.

`ZWPUPDATE` 또는 편집기의 **업데이트 확인**에서 새 버전을 확인하고 설치할 수 있습니다. 업데이트 파일의 서명된 해시와 설치 결과를 검증합니다. 프로젝트는 별도 사용자 폴더에 저장하세요.

## 온라인 버전 정책

0.5.0부터 시작 시, 작업 시작 전, 실행 중 주기적으로 사용 가능한 버전인지 확인합니다. 연결 실패, 정책 검증 실패, 사용 중지 또는 필수 업데이트 상태에서는 새 작업이 제한됩니다. 이미 편집하던 프로젝트의 저장과 기존 도면은 보존합니다.

계정 로그인은 사용하지 않습니다. 버전 정책 확인이나 업데이트 요청에 프로젝트·도면을 업로드하지 않습니다. 운영자는 지원 버전을 변경하거나 버전 사용을 중지할 수 있습니다.

`channel/stable.json`은 서명된 운영 정책입니다. 설치 프로그램에는 검증용 공개키만 포함됩니다. 운영 정책은 관리자만 갱신합니다.

## 안내

설치 EXE는 현재 Authenticode 서명이 없습니다. 반드시 이 저장소의 배포 파일을 사용하세요. 입력 데이터와 설계 조건에 맞춰 계산 결과를 검토하세요. 구성요소 라이선스와 고지는 설치 폴더에 동봉합니다.
